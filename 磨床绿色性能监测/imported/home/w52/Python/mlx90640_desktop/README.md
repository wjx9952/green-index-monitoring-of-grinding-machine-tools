# 热成像与空气质量综合监测

双击桌面的“MLX90640 热成像仪”快捷方式即可启动综合监测界面。

- 上方实时显示 32×24 热成像和最高、最低、中心温度
- 下方统一显示 TVOC、MQ-135 和粉尘传感器的全部指标
- TVOC 串口显示 AIR、CO₂、CH₂O、TVOC；Pico 串口显示 MQ-135 与粉尘数据
- MQ-135 报警或粉尘达到 75 μg/m³ 时以红色提示
- 可通过 LoRa 每秒广播全部传感器数据；热成像广播最高、最低和中心温度
- 支持自动温标和手动温度范围
- 支持四种色彩方案、暂停画面和保存截图
- 截图默认保存到 `~/Pictures/MLX90640`

程序使用已有的 `/home/w52/mlx90640-env` Python 环境，不影响原来的
`/home/w52/mlx_live.py`。

LoRa 默认使用 `/dev/ttyAMA0`、868 MHz、地址 0、22 dBm 和 2400 bps
空中速率。HAT 的 M0/M1 跳帽需拔除，账户需有 `gpio`、`dialout` 权限。
